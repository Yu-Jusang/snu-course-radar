# 빈자리 · SNU Course Radar

서울대 공개 강좌의 장바구니 경쟁률과 수강 잔여석을 비교하는 비공식 학생 도구.

- 사이트: https://Yu-Jusang.github.io/snu-course-radar/
- 출처: https://sugang.snu.ac.kr/ 의 로그인 없는 전체 강좌 검색
- 정렬: 장바구니 여유 / 낮은·높은 경쟁률 / 초과 인원 / 수강 잔여석 / 정원 / 강좌명
- 검색, 이수 구분·학과 필터, 장바구니 미초과만 보기, 즐겨찾기, CSV 내보내기

## 데이터 기준

`capacity`는 원본의 `수강신청인원/정원(재학생)`에서 `/` 뒤 정원, `enrolled`는 `/` 앞 수강신청 인원이다. 괄호 안 재학생 정원과 총수강인원도 별도 저장한다. `basket`은 카드의 `장바구니` 수치다. 장바구니 여유 = 정원 − 장바구니, 경쟁률 = 장바구니 / 정원, 수강 잔여석 = 정원 − 수강신청 인원. 0 정원 및 미확인 경쟁률은 정렬 마지막으로 보낸다. 누락 수치를 0으로 치환하지 않는다. 장바구니 미초과 필터는 양수 정원에서 동률을 포함한다.

취소여석, 장바구니보류, R 등 원본 제한 표시를 보존한다. 양수 잔여석은 즉시 신청 가능 보장이 아니다. 원본에서 현재 선택된 학기를 매번 읽고 해당 학기의 전체 강좌를 수집한다. 학기 변경 시 자동 전환된다. 과거 학기 선택은 현재 지원하지 않는다.

## 갱신

GitHub Actions가 매시 03/13/23/33/43/53분에 수집을 시도한다. 예약 실행은 지연·누락될 수 있으며 정확한 10분 실시간 보장은 없다. 브라우저에서도 10분마다 **저장된 JSON**을 다시 읽는다. 데이터가 30분 이상 오래되면 지연으로 표시한다. GitHub는 공개 저장소 활동이 장기간 없으면 예약 실행을 중지할 수 있으므로 운영자는 Actions 상태를 확인한다.

수집기는 독립된 비로그인 브라우저에서 홈페이지의 정상 대기 절차를 따르고 공개 검색 버튼을 누른다. 로그인·개인 장바구니·수강신청·보안문자 입력은 하지 않는다. 요청은 페이지별 직렬 처리하며 최소 1.6초 간격을 둔다. 전체 261개라면 27개 결과 페이지를 읽는다. 대기열 통과 실패 시 중단하며 우회하지 않는다.

전체 건수, 필수 항목, 중복 여부를 검사한 **완전한 스냅샷만** 교체한다. 실패 시 마지막 성공 JSON을 유지하고 별도 상태 JSON에 실패를 표시한다. 실패 상태도 Pages에 배포된다. 수집 시작~완료 사이 수치는 동일한 순간의 원자적 스냅샷은 아니다.

## 로컬 실행

Node.js 22 이상:

```sh
npm install
npx playwright install chromium
npm test
npm run collect
python -m http.server 4173 --directory docs
```

Windows 수집은 설치된 Chrome을, Linux Actions는 Playwright Chromium을 사용한다. 정적 화면은 외부 API 키나 로그인 없이 실행된다. Google Fonts를 불러오지 못하면 시스템 글꼴을 사용한다.

## 배포

GitHub Pages의 Source는 GitHub Actions. `main` 푸시는 테스트 후 기존 스냅샷을 배포하고, 예약 실행 또는 수동 Run workflow는 수집 → 검증 → 데이터 커밋 → 배포를 수행한다. 기본 GITHUB_TOKEN 이외의 비밀키는 필요 없다. 중단은 Actions에서 workflow를 Disable하면 된다.

## 공모전 설명에 사용할 수 있는 범위

ChatGPT/Codex를 활용해 학생의 요구를 정리하고 공개 데이터 수집, 정렬 도구, 검증 및 배포를 구현한 프로젝트다. 서비스의 순위 계산은 명시적인 산술식이며, 방문자의 질의를 실시간으로 ChatGPT Edu에 보내는 기능은 없다. ChatGPT Edu 공식 연동 또는 공모전 수상·승인을 의미하지 않는다.
